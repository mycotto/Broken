# 《Broken》0.0.3 攻略与注意事项

这份说明对应 Windows 0.0.3 版本。游戏里的数值、遗物和随机事件会改变局面；把它当作理解规则的手册，而不是一条固定解法。

## 一局游戏怎么推进

1. 选择职业后进入探索，每次前进会遇到战斗、事件、宝箱或奖励。
2. 清理房间并积累遗物、药水和职业资源，推进到每层的首领。
3. 战斗中先由你行动；行动结束后，敌人逐个发动攻击。
4. 敌袭时，中央框会公开**敌人、招式、攻击判定和原始伤害**。根据自己的构筑选反制，结算后会显示防御成功或失败。
5. 第二层起，探索会持续消耗记忆；记忆归零同样会结束本局。

药水栏最多放 3 瓶。进入精英和首领战前，优先检查生命、护盾、药水和关键技能冷却。

## 先看懂战斗面板

- 顶部压缩状态条：我方与敌方的 HP、护盾、AC、异常状态及职业资源。
- 中央敌袭框：只给出本次敌方的公开事实，不替你算哪一种反制更好。
- 右侧行动区：在自己的回合选择技能；在敌袭时选择反制。
- 战斗记录开关：想复盘骰值、遗物触发和护盾吸收时再展开，不会遮挡当下的决策。

中央框中的“防御后伤害”是反制结算后的伤害；随后仍可能被遗物修正，并由护盾优先吸收。

## AC 是什么，怎么用

AC（Armor Class，护甲等级）是角色的**硬抗判定值**，不是减伤百分比，也不是敌人的伤害。

选择“硬抗”时，游戏计算：

```text
差值 = 本次 AC − 敌方攻击判定
```

| 差值 | 硬抗结果 |
| --- | --- |
| 5 或以上 | 完美格挡，伤害为 0 |
| 2 至 4 | 受到原始伤害的 20%，至少 1 点 |
| 0 至 1 | 受到原始伤害的 30%，至少 1 点 |
| 小于 0 | 硬抗被击穿，承受原始伤害 |

例如你的 AC 为 16，敌方攻击判定为 13，差值为 3：硬抗会把伤害压到原始伤害的 20%。同一敌人的“攻击判定”和“来袭伤害”是两件事：前者决定 AC 防住多少，后者决定防不住时有多痛。

### AC 的实战注意事项

- AC 越高，硬抗越稳定；但面对远高于 AC 的攻击判定，闪避、招架或职业反制可能更合适。
- “守卫姿态”会让战士 AC +3，并提供下一次攻击命中与伤害加成；加成在敌方阶段结束后撤销。
- 法师的“奥术屏障”消耗 1 层充能，提供 6 点护盾，并只为本次硬抗提供 AC +3。
- 魔剑士的部分魔装会提供 AC；魔装会在战斗中逐回合消散，注意顶部状态条的剩余回合。
- 敌人也有 AC：你的攻击判定达到敌方 AC 才会命中。攻击判定加成和伤害加成不是一回事。
- 护盾不会提高 AC。正确顺序是：先完成反制减伤，再由护盾吸收剩余伤害，最后才扣 HP。

## 防御方式速查

| 方式 | 成功条件与效果 | 适合的局面 |
| --- | --- | --- |
| 硬抗 | 用 AC 对比敌方攻击判定；按上表分段减伤 | AC 高，或敌方攻击判定不高 |
| 闪避 | `d20 + 敏捷调整值` 对比攻击判定；差值 5/2/0 对应 0%/20%/50%伤害 | 敏捷高，想搏免伤 |
| 招架 | `d20 + 力量调整值` 达标后抵消 `1d8 + 力量调整值` 伤害 | 原始伤害高，且力量较强 |
| 能量对冲（法师） | 智慧检定成功受 30%伤害；失败受伤 +35%，但获得 1 层充能 | 充能收益值得承担风险时 |
| 魔装疾闪（魔剑士） | 闪避检定额外 +5，冷却 2 | 高威胁攻击或需要保 HP 时 |
| 魔装招架（魔剑士） | 力量检定额外 +6，且每件魔装再提供 +1 判定 | 已装备魔装、希望稳定招架时 |
| 高阶闪避（影舞者） | 闪避检定额外 +4；成功获得影痕 | 为影痕处决铺路时 |
| 烟幕（影舞者） | 先掷 d20，结果大于 10 时本次敌方攻击判定 -3，再按硬抗结算 | 敌方判定刚好压过 AC 时 |
| 替身（影舞者） | 完全抵消本次伤害，冷却 3 | 不可承受的一击 |

这里的“调整值”按属性计算：`属性调整值 = floor((属性 − 10) / 2)`。第三层起可能出现“规则崩溃”，它会降低所有判定掷骰；因此不要只看角色面板上的基础属性。

## 职业玩法提示

### 战士

定位是稳定推进。用守卫姿态抬高 AC 后硬抗，面对高伤害时再用招架。护盾猛击既补护盾又能输出，适合在下一轮敌袭前建立缓冲。

### 法师

核心是充能节奏：奥术飞弹与奥术洪流用于积累充能，3 层充能后可施放本场随机准备的 3 个高阶法术，每个只能施放一次。低 AC 时不要机械硬抗；奥术屏障是“护盾 + 本次 AC”的保命工具，能量对冲则是高风险换资源。

### 魔剑士

魔装带来短期峰值。留意魔装提供的是 AC、攻击判定、伤害还是每回合护盾；首次契印换装可能免费，后续血祭换装会失去 3 HP。防守时优先考虑魔装疾闪和魔装招架的固定加成。

### 影舞者

影痕是爆发资源：攻击落空与高阶闪避成功都会累积影痕，2 层可发动必中处决。匕首连击命中有 -3 修正且每击伤害较低，适合试探；遇到危险攻击时，用替身保命，或用烟幕把刚刚越过 AC 的攻击判定压回去。

## 少走弯路

- 不要只盯原始伤害：先看敌方攻击判定与你的 AC、敏捷和力量路线是否匹配。
- 不要把护盾当成 AC；护盾是结算末端的生命缓冲，AC 决定硬抗能减掉多少。
- 不要默认“防御成功”就等于零伤害。成功也可能是部分减伤；看中央框的防御后伤害与顶部护盾变化。
- 道具和技能的“本场”效果通常在战斗结束时失效；首领前再使用关键消耗品更有价值。
- 面对多名敌人时，守卫姿态的 AC 加成会覆盖整个敌方阶段；但护盾会被前面的攻击消耗，留意后续敌人的来袭。
